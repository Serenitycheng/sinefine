# 微光街区 · Lumen Quarter

俯视像素风现代魔法街区。最初有20位重点居民和60位背景居民，均使用动漫风日语姓名。居民会工作、交往、学习魔法、组建家庭、养育后代、成长和衰老。你通过规则与干预观察社会。

## 开始体验

点击地图下方播放按钮运行世界；空格键暂停。地图人物和居民列表均可选中观察。右侧查看状态、关系、家庭、记忆和决策理由。名字旁的星标切换重点观察。

“规则”允许编辑数值、公共制度，或先解释自然语言再确认生效。“设定”是可选的特殊事件系统，可自定义名称、背景、人数、最低魔法等级、研究/合作/竞技目标、期限与奖励。默认关闭。它不是固定作品或固定剧情。

“介入世界”可投放资源、治疗居民、改变天气。部分居民可能察觉异常并积累信念。“时间远行”可推进1天、30天、1年、10年，并生成重要事件回顾。星历每年360天，可选择遇到重点人生变化时暂停。

## DeepSeek

在“设置”填写已有密钥，点击“验证连接并读取模型”，选择模型。可以先在重点居民面板点击“AI 决定”，再开启自动调用。自动调用在1倍或4倍速度下每约20秒处理最多4人。请求次数与返回tokens可见，每次页面默认最多30次生成请求。

密钥仅保留在页面内存，经本站后端转发至固定的DeepSeek官方接口，不会写入存档。刷新后重新填写。长时间快进和24倍速度采用本地规则。未连接时全部使用本地模拟，界面明确标注。

## 保存

世界每20秒自动保存到当前浏览器，也可手动保存。保留最近3个关键时刻快照，支持导出与导入JSON存档。设备与浏览器间不会自动同步。读取无效存档会保留原世界；恢复和重开前先保存当前快照。

## 当前实现范围

- 有限行为系统与AI决策结合。AI只能提出受支持的行动，资源、地点、年龄与事件资格由模拟系统校验。
- 支持5个魔法领域；遗传采用简化的天赋与外观继承、随机变异。子女需要学习知识，性格也受照料者影响。
- 组织可由关系与兴趣形成，研习社和互助会对知识与资源产生实际影响。新物理机制、任意复杂制度、动态建设与城市扩张仍需扩展。
- 特殊设定的背景文字供AI理解，结算目前支持研究、合作、竞技3类规则。不限具体作品，但任意新超能力不会自动成为可执行机制。
- 驯龙以信任进度表示，尚无可操控骑乘动画。天气目前影响画面与异常感知。
- 此版一个可玩世界；作品角色资料可以手动录入。多世界内容包、独立生态/物种演化与桌面包装为后续方向。
- 本地日常对话来自与真实事件绑定的文本模板；连接AI后记录其真实返回内容。模型不是持续调用。模拟时间在不同速度下可能出现不同发展。
- 世界事件最多约5000条，压缩时优先保留近期与重要记录。每位重点人物索引最近300条记忆，背景人物30条。请导出阶段快照保留长期历史。

## 开发与验证

保留Sites/Vinext脚手架。npm run dev启动；npm run build生成Cloudflare Worker；npm test运行13项模拟测试；npx tsc --noEmit检查类型。

已验证：完整年度推进、固定种子的同节奏可复现性、地图路径、规则边界、生育与遗传、成年与衰老、特殊事件期限、AI行动地点限制、存档损坏保护。真实DeepSeek生成尚未用用户密钥验证。已在浏览器的WebMCP环境验证读取和选中居民、参数失败处理；未执行全面浏览器UI自动化测试。

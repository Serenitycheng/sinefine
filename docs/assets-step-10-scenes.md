# 第 10 条：街景素材

制作方式：内置 imagegen。以原有 `source/public/fate/street/street.png` 作为**画风参考**，为新地点分别生成独立背景；原图继续用于咖啡店。最终素材放在 `source/public/fate/street/scenes/`。这些独立视角的插画用于地点详情和进入后的可行走近景，不再拼贴到整张街区画布上。

共用提示：横向 16:9、行人视角的 2D 动漫游戏街景；保持原图的暖色、半写实绘景和建筑质感。画面下方约四分之一留出连续、无遮挡的可行走人行道与路面。不要人物、可读文字、界面、地图或俯瞰视角。

各图在共用提示基础上分别指定：

- `einzbern.png`：切嗣一家新居，浅色石木住宅、围墙花园、铁门和桦树。
- `emiya.png`：卫宫宅，传统两层木屋、瓦顶、矮墙、小庭院和厨房窗。
- `tohsaka.png`：远坂宅，红砖洋馆、铸铁围栏、庭院门与树木。
- `matou.png`：间桐宅，年代久远的深色木宅、旧墙、繁茂庭院和大门。
- `waver.png`：韦伯住处，街角书店楼上的普通公寓、自行车与盆栽。
- `temple.png`：柳洞寺，木门、通往寺院的石阶、杉树和石灯笼。
- `church.png`：教会，斜坡街道上的小石教堂、钟楼、拱窗和庭院。
- `kayneth.png`：肯尼斯住处，米色石材联排住宅、黄铜门框与小庭院。
- `fujimura.png`：藤村家，宽木门、陶瓦屋顶、鲜花与树木。

这些是早期 2D 街景概念背景；真正可自由环视的 3D 人物、场景与动作现已暂停，后续先按[2D 打磨顺序](roadmap.md)制作可运行的连续场景。

补充：`source/public/fate/street/fuyuki-city-miyama.png` 是原创的双岸俯瞰绘景，供地图和街区行走底图共用。`source/public/fate/street/scenes/new-city-link.png` 是咖啡店与商店侧巷之间的近景连接路段。二者也是 imagegen 生成的 2D 概念素材，遵循[地图取舍](fuyuki-geography.md)，并非原作官方地图。

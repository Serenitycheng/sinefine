# 远坂宅正式接入

更新：2026-10-12。仓库 `D:/projects/sinefine`，分支 `feat/art-samples`，HEAD `6b1b1d9`。本阶段仅本地开发、构建和验证；未提交、推送、合并或部署。

## 现在可以玩到的内容

- 在本地 `/fate/street` 选择凛、进入角色，沿路到远坂宅真实门口后进屋。玄关、会客书房、餐厅、卧室、魔术工房五室使用既有 2.5D 原画、人物动作、家具遮挡和双向门。
- 正式场景固定控制凛，隐藏预览人物选择。原街道控制与宅内控制互斥；街道循环只保存宅内进度，日常计时由宅内场景单独推进。人物速度沿用原设置。
- Archer、时臣、吉尔伽美什及实际到访的樱复用已有模型；根据主世界实际在家状态出现，住址本身不制造人物。常规房间变动通过真实门和玄关路径移动，避让控制角色和其他身体。
- 点击人物或人物名字会沿地面靠近，再按原规则交谈；支持附近 E，保留原有房间、忙碌与重复话题检查。对话同时进入主历史和日常记录。
- 用餐、歇息、小睡与睡到早上沿用原居家机制，并推进其他居民的日常。明确跳过整段游戏时间后，对齐人物的新状态，不保留已经外出的身体；不新增库存或经营管理。
- 退出从实际出口走回街道，保留凛的精确世界脚点、街道相机、手动取景与两档缩放，并保留生活变化。重新进屋从玄关开始。

## 主记录与兼容

- `FateSave` 增加 v3，`house` 侧记录保存远坂宅房间、局部脚点、朝向、家具动作、缩放和居民位置。原世界坐标仍放在 `life.positions`；原四类生活房间仍用于现有生活与交谈逻辑，不将样本坐标写入世界。
- v1、卫宫宅 v2 继续可读；v3 可保留已经退出的远坂宅与卫宫宅记录，只允许一处正式场景处于控制中。库封装、备份和检查点格式保持，扩展主记录校验。
- 刷新恢复具体房间、站位、坐姿和缩放，停止移动与日常。加载、失焦和隐藏页面仅清输入，不抹去已保存坐姿，也不在房间卸载时覆盖下一间的入口。
- 页面与服务端都拦截正式宅内开启后台日常；后台轮次同样拒绝正在控制的正式场景，防止第二个时钟。实际云接口、付费 AI、数据库与定时任务未实测；新 v3 记录需要随本轮代码一起发布。
- 原子主记录写入、备份解析及其他页面冲突保护复用原流程。另一页面改动主记录时暂停旧场景，原始记录与新进度不被旧控制器覆盖。

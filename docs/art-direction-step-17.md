# 融合版画风基准

唯一确认基准：[融合版街道样图](art-direction/step-17-approved-anime-street.png)。采用 P1 的自然光影、P2 的动画背景笔触和 P3 的舒适构图，呈现日式普通街道；不采用像素风、魔法学院风或仅靠降低饱和度的画面。

## 当前保留

- 融合版样图。
- 建筑图集：`source/public/fate/environment/fuyuki-building-atlas-v2.webp`。
- 道具图集：`source/public/fate/environment/fuyuki-prop-atlas-v1.webp`。
- 地面图集：`source/public/fate/environment/fuyuki-terrain-atlas-v1.webp`。
- 与修正后的冬木道路、两座桥和入口共用坐标的 2D 绘制代码，以及原有角色、室内与地点卡功能素材。

图集是沿用该方向的第一轮素材，**不等于实际街区已达到样图效果**。其余角色和室内也尚未完成统一美术打磨；保留基础功能不代表这些画面已最终验收。

## 后续要求

- 先完成[开发顺序](roadmap.md)第 16—22 条机制与可玩性，再制作一个小区域的统一效果样板。
- 斜俯视可辨认路面、立面和屋顶；人物脚点、道路、门口和遮挡使用同一位置关系。
- 人物、建筑与环境比例统一，光影自然，边缘和材质有动画背景的柔和笔触，不靠静态图片拼接冒充连续行走场景。
- UI 沿用克制的暖金和深绿色，清楚文字、留白与按需展开，不把内容堆成密集日志。
- 只有实际运行画面获得用户确认后才扩展全城；完整 3D 街区和人物建模继续放在最后。

使用独立 Chrome 测试会话，不读写用户日常浏览器中的存档。AI 使用测试密钥和模拟响应，没有请求真实模型。

- 检查桌面及 390×844 手机尺寸：首页与街道正常显示，街道无页面横向溢出。手机端已有的底部说明文字较拥挤，后续交互优化时处理。

## 设定与存档

- 从界面编辑世界、人物和关系备注，保存并刷新后保持。
- 韦伯青年/成年切换，以及樱凛同住、Saber 随凛居住，刷新后保持。
- 保留本地备份 A，继续修改为进度 B。
- 下载按钮生成的实际 Blob 捕获为 JSON 文件，再由文件选择控件上传；导入预览期间当前进度仍为 B。
- 确认导入后恢复 A，自动保留 B 为「恢复前的进度」；刷新仍为 A，再恢复保护备份可回到 B。取消恢复不改变进度。
- 损坏 JSON、错误格式及超过 5 MB 的文件均拒收，不产生可恢复预览；存档库内容与导入前逐字一致。

## AI 成功、失败和取消

- 通过设置界面验证模拟连接并读取模型，成功对话保存到正确角色组合且清空草稿。
- 模拟 HTTP 503：显示错误，草稿与既有历史保持；恢复成功响应后直接重试，正常保存。
- 请求等待期间关闭对话窗，确认取消信号触发。随后刻意返回迟到的成功响应，历史仍不变；刷新后也没有迟到回复。
- 自主行动请求失败后关闭自主 AI，显示原因，本地时间和预设相遇继续推进。
- 浏览器未记录未捕获的应用异常。

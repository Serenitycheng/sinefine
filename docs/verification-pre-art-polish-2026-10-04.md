# 美术前功能与 UI 收尾 · 2026-10-04

范围：在主仓库保留第 1—15 条基础功能与第 16—22 条生活机制，检查现有试玩流程。没有扩展美术、恢复 3D 实验、提交或推送。

## 本轮已修复

### UI 与操作

- 地图目录与手账互斥显示，解决点击手账后仍被目录挡住的问题。
- 街道活动入口直接打开「一起做事」；约定入口打开对应栏目，不会停留在上次的记录设置页。
- 切换受控人物时，手账人物筛选重新对应当前人物；赴约反馈按人物、约定及状态限定，切换观察对象清除旧反馈。
- 后台代管说明移入独立设置弹窗，主界面只保留状态与入口。手机不再多出约 261px 的常驻说明；设置中保留账号登录入口，后台保护暂停期间仍可访问。
- 游戏区域适配剩余高度，调整窄屏顶部按钮、工具条换行和底部帮助；地点按钮与交谈按钮不再占同一位置。
- 点击镜头或时间按钮后仍可用 WASD、方向键移动；输入框、对话框、手账原生方向键及系统快捷键继续受保护。
- 对话窗口适应低高度视窗并可滚动，避免标题、话题与发送区域被裁切。根据可见视窗调整位置与高度，为软键盘留出空间。
- 最近对话达到 120 条上限后，仍按最新对话 ID 滚到新回复，不依赖记录总数增长。

### 人物行动与记忆

- 小活动记录达到 32 条时，先淘汰已结束记录，保留仍在准备或进行中的活动。
- 再次询问喜好时尊重明确偏好，不会把刚表达的不喜欢重置为默认喜欢；没有可确认的喜好时不凭空生成。
- 「聊聊上次一起做的事」读取双方当前时期的真实共同记忆，不再因活动日志滚动而否认经历；第三人和韦伯时期继续隔离。

### 后台进度保护

- 曾开启后台代管的页面在读取超时、失去登录状态或切换账号时，保持本地暂停，避免同时推进两份故事。
- 开启请求发送前记录交接状态，服务器可能已接受但响应丢失时也不会直接恢复本地。
- 成功确认原账号后台状态并处理进度后解除保护。无交接记录的新本地玩家不会被这项保护锁住。

## 追加收尾：住宅、拥挤、到场玩法与双速度设置

- **住宅**：10 户增加连接原街道与建筑实际门前的可走步道。碰撞、点击寻路、地图图钉、街道入口和进入住宅使用相同坐标；旧住宅锚点继续兼容。门前进屋的存档校验已同步，刷新后能恢复室内并原路出门。住宅按钮位于人物上方，已到场的“回到街区”只关闭卡片。
- **NPC 拥挤**：商店、咖啡店、公园使用居民各自的可走站位，至少相隔 60 个逻辑单位。旧存档中的叠放人群会保留任务和剩余时间、沿路分开，不瞬移、不接管玩家。拥挤时优先显示当前人物与可交谈对象名字。本轮没有加入全城人物刚体碰撞；途中交错不等于停留时堆叠。
- **咖啡店**：饭团定食、时蔬配餐、热茶三种选择；点单、真实留场、中途选择节奏、用完收尾组成完整过程。热茶恢复精力但不替代饭菜；时蔬只扣一次。取消不算完成，45 游戏分钟的冷却独立保存，不会因短日志滚动被绕过。
- **河岸公园**：听风和寻找小鸟两条路线，各有两个实际可走观察点；走到现场停留、查看线索、决定如何接近、到下一点记下发现。同行需要双方真正到场，作息和紧急需求优先；仅共同完成才写入双方记忆。当天只结算一次，不以重复刷奖励作为主要吸引力。
- **活动保存与 UI**：单人完成经历进入个人手账；进行中活动随存档恢复，暂停、离场、进屋、换人不会凭空计时。活动有常驻继续入口，观察点可点击导航；手机活动卡改为最多 520px 的可滚动浮层，避免原先被街道区域挤到仅 150px。
- **时间**：默认现实 6 秒推进游戏 1 分钟，比原先默认节奏放慢。顶部可选 0.5×、1×、2×、4×，对应 12、6、3、1.5 现实秒/游戏分钟。取消旧“行走时偷偷降为 1×”规则。
- **步速**：慢走 0.65×、正常 1×、快走 1.4×，独立于时钟；统一作用于玩家键鼠/点击/手柄路线、室内、NPC 日程和同行。动画节拍适度随走速调整。两项偏好单独存于当前浏览器，刷新后保留；不改变已约定的后台半小时执行方式。

## 后续完善项，不混入本轮修复

- 受控人物目前保留既有的需求冻结规则。NPC 有完整吃饭、休息和日程循环，玩家可手动用餐，但完整的手动休息／睡眠与需求消耗联动仍需单独设计后启用，避免只增加消耗而缺少恢复入口。
- 部分小活动回应仍是通用台词；之后按人物补充表达差异和少量后续事件，比单纯增加数值或重复任务更有价值。
- 当前街区和室内是可运行的基础呈现，不等于融合版最终美术已达标。下一轮继续以一小段场景和自然动作作为样板，确认后再扩展。
- 不把自动测试等同于「已经好玩」：仍需用户实际试玩，尤其判断操作发现性、日常节奏和反馈是否有吸引力。

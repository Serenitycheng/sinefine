## 入口与技术

- `/fate/street`：正式游戏机制所在页面。
- `/fate/city-art`：地图驱动的全城美术独立预览，含纯 2D 总览与 2.5D 街区；尚未接入正式 NPC 生活与存档。
- `/fate/emiya-life`：卫宫宅士郎生活试玩，复用原时间／需求／居民日程、实际身体与关系记忆，新增家庭邀请和共同家务；使用单独本地记录，尚未接入正式街道与主存档。
- `/fate/art-sample`：旧的小区域融合版样板；`/fate/art-sample-3d`：对照实验，不是当前全城路线。
- React 19 / Next 16 / TypeScript；街区是**完整背景原画＋共用世界地面配准＋人物动作图＋本地投影、碰撞与导航**。背景不是可自由旋转的完整 3D 模型；Three.js 用在样板的本地纵深／3D 对照。保留路线，不拼建筑卡片，不把 2D 扭曲说成 360° 环视。
- 原 `CITY_ROADS`、住宅入口、地点 ID 与存档世界坐标不重排。全城素材覆盖 7 个分区、19 条原道路，拆为 23 个街景×3档取景＝69 幅；36 处实际共享路口。远坂、间桐各有真实庭前通路。素材覆盖≠全部游玩体验已验收。
- 已确认柔和融合版：日式动画背景、自然暖光和冷色树影、结构可读，不以单纯低饱和／模糊代替柔和。每处建筑、树种与花卉有区别；平视应接近人物眼高。当前原画约 1672×941，尚非 4K 母版。

## 本轮街区操作收尾

- 核对 23 个街景、36 处共享路口及 19 处入口（10 住宅、4 公共地点、5 本地店面）的双向可达；原道路、地点 ID、庭前通路和世界坐标均保留。
- 街景显示真实入口／出口落点；画面外的标签带方向箭头并可点击沿路前往。远坂庭前与圆藏山参道各有明确双向出口。小地图使用总览的道路与坐标，显示人物、道路、入口、出口，点击打开总览。
- 总览支持直接点击 19 处建筑／店面或可走道路，从当前位置沿实际通路跨街前往；到门前才显示地点卡。途中保留目的地，不跨河抄近路，也不直接移动人物。地图拖动不触发行走，手动方向或停止可取消路线；街道目录默认隐藏。
- 镜头统一约束背景边界和人物全身范围，拖动从实际显示偏移开始；跨街保留取景、倍率、世界位置。极高倍率下只限制人物显示大小，避免全身超过视窗；普通倍率仍沿用原透视比例。背景母版与人物素材未改、未重新生成。
- 补上真实方向键的投影判定，跨街沿选中道路延续按住的方向；方向按钮不再在转场时失去按住状态。新一轮操作修正将普通跨街淡入改为 220ms，有可走路径时继续移动；明确换取景仍等待短过渡，松开即停，Escape 可在转场中停止。
- 验证范围和具体剩余问题见 [本轮街区验收](street-operations-2026-10-09.md)。

## 街道操作手感修正

- 默认自动跟随采用中央稳定范围与时间平滑；滚轮围绕鼠标、按钮围绕人物、双指围绕中点缩放，世界坐标不变。拖动、失焦和后台停步。Q/R 或 V 换取景，Home 完整街景，F 跟随，Escape 停止，M 总览；路口 1–4 选明确支路。
- 明确换取景后按键对应新画面；跨街保留道路朝向。普通跨街 220ms 淡入中继续行走，旧画面不再绘制第二个人物。点地面优先碰撞安全的可见直线，转身加入斜向缓冲。
- 实际门口可点；到门前优先聚焦进入室内，Enter／E 可进屋；室内操作隔离门外镜头。标签避开完整人物。手机从路面或入口／出口标签开始的双指手势都不会误选路线。
- 新入口：`source/lib/fate-city-art-controls.ts`；现有 `fate-city-art.tsx`、`fate-city-art-navigation.ts`、`fate-city-art-map.ts` 与 `fate-city-wayfinding.tsx` 承担控制、路线、支路和避让。正式素材、原生活／招呼文件和室内组件保持不变。

# 间桐宅正式接入

更新：2026-10-12。仓库 `D:/projects/sinefine`，分支 `feat/art-samples`，HEAD `6b1b1d9`。仅本地开发与验证；未提交、推送、合并或部署。

## 当前玩法

- 在本地 `/fate/street` 选择樱、雁夜或美杜莎，进入角色，沿路到间桐宅真实门口后进屋。玄关、起居厅、餐厨、樱的房间、地下家族资料间五室复用现有原画、家具、遮挡、人物四向步态与坐读动作；各分支通过真实双向门行走。
- 控制人物固定为从街道进入的实际身份，隐藏预览选人；街道与宅内控制互斥。刷新恢复房间、局部脚点、朝向、家具动作与缩放，停止移动和日常；出门恢复原世界脚点及相机记录。
- 樱、雁夜、美杜莎根据主世界实际在家状态出现，实际到访的凛复用远坂模型。住址、回家途中或角色名单不等同在场；本人不会再被画成第二个居民。常规房间变化走真实地面与玄关双向门，保留身体避让和门口等待。
- 点击人物或名字先沿地面靠近，再按现有规则交谈；附近 E、忙碌／房间／重复话题检查仍有效，对话写入主历史及原日常记录。吃饭、歇息、小睡及夜间睡到早上复用原居家规则与时间推进，不新增库存或经营管理。
- 姐妹同住、从者御主关联和所有身份保持。若樱或美杜莎的实际住处已改到远坂，仍可控制她们到间桐宅访问；居家吃饭／休息要求回到自己的住处，沿用原限制。没有自动将住处改回间桐。

## 适配与存档

- `fate-house-game.ts` 将远坂适配扩展为按住宅与人物选择的规则，间桐映射为玄关→hall、起居厅→lounge、餐厨→table、卧室→rest、资料间→study；保留远坂会客书房与魔术工房原映射。样本局部坐标不写进原世界坐标。
- 保持 `FateSave` v3 和 `house` v1 字段版本，扩展住宅／人物合法组合校验。原 v1、卫宫 v2、凛→远坂 v3 继续可读；拒绝跨住宅房间、错误门口、身份不一致、重复本人及重叠身体，不改动被拒绝的原始记录。
- `house` 保存当前或最近一次共用宅内场景；另有卫宫 `emiya` 侧记录，只允许一处正式场景活动。退出后重新进宅从玄关开始，本轮没有增加每栋住宅的独立恢复列表。
- 原子库写入、备份解析和不同页面冲突保护沿用已有机制。正式场景独占日常时钟，街道循环只保存；既有后台前后端防重复计时覆盖间桐。实际云接口、付费 AI、数据库及后台任务未实测。
- 主角色目前没有慎二；本轮按实际已存在的樱、雁夜、美杜莎接入，没有擅自新增身份。前阶段远坂接入文档的“樱／慎二／雁夜”下一步描述有误，以本次实际核对为准。

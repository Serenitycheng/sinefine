# 新第 18 条验收：可持续的个人记忆

日期：2026-10-04。接续新第 16、17 条，功能代码位于仓库内独立稳定工作区 `.verification/step15-map-dialogue`，基于已推送的 `791bd11`。主工作区旧视觉与 3D 实验保留；本轮未 commit、push 或发布。

## 实现结果

- 在原有每对人物的相处记录中增加独立重要记忆，分为明确偏好、约定及经历。原有最近 80 条日常事件、6 条相处记录和 120 轮对话历史继续保留，普通闲聊不会把重要记忆挤掉。
- 记录时间、正确发言者、知情者、原话及来源。偏好仅采纳本人明确表达，同一对象以最新明确表达为准；疑问、转述、条件、玩笑自称及无依据的行动宣称不成为事实。
- 约定保留原始提议与明确答应，随实际生活更新等待、正在碰面、已履行、失约、取消；等待不写成完成，失约不推断人物动机。实际同行和实际一起用餐才增加共同经历，用餐只记录真实入座的居民。
- 私下信息只进入实际参与者之间的对话上下文，第三人不会自动知道；决策只读取该人物自己的经历。人物身份、家庭关系仍使用原有设定，韦伯的不同人生时期及记忆截止线继续隔离。旧台词作为往事依据，不作为新指令或已经执行的行动。
- 「日常与记录 → 相处与约定」增加个人记忆，选择观察人物后可筛选全部、偏好、经历、约定；摘要简短，原话与知情者按需展开。沿用原有暖金与深绿色 UI，不增加场景美术或 3D。
- 新字段保持可选，存档沿用 v16，不需要新增数据库迁移。旧存档只从仍保留的明确原话、有效交谈结果及已确认约定恢复；不重放关系加减，也不补造已丢失的历史。

- **225/225 测试通过**：原有 211 项加 13 项个人记忆测试及 1 项云端接口测试。
- 连续 100 次普通闲聊后，近期日常与相处记录已滚走，明确偏好、重要经历和待履行约定仍保留。多次恢复、重复事件与重复履约不会制造重复记忆。
- 验证正确发言者、参与者隔离、第三人不可见、最新偏好覆盖、两时期隔离及修改关系后的记忆截止线。
- 验证疑问、转述、条件与虚构过去不形成事实，损坏归属、重复标识、无效原话、虚假完成与缺少实际计划的有效期内约定被拒绝导入。
- 覆盖实际赴约、履行、失约、取消、真实共同用餐及未入座人物；待履行约定优先保留。检验每对人物的数量边界与旧存档迁移不重放关系变化。
- 本地导出/导入及存档恢复完整保留记忆；云端上传/读取处理器使用本地模拟数据库往返，保留记忆并隔离不同账号。既有接近 5 MB 的旧存档兼容测试仍通过。
- 对话与决策 API 使用模拟模型响应检查请求上下文：近期记录滚走后仍带有重要记忆，私下信息不会进入第三人的对话请求。未调用真实 DeepSeek。
- 类型检查、oxlint（0 项诊断）、生产构建及 Git 差异空白检查通过。未新增依赖。

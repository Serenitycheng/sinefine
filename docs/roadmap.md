# SINE FINE｜无终之庭 后续开发顺序

工作目录：`D:\projects\sinefine-recovery`。按编号逐条推进，每完成一条单独汇报，并在 `development-progress.md` 记录验收结果。以下是当前范围，实施中如发现依赖或体验问题，再明确调整顺序。

## 10. 冬木市地图与连续行走场景（本地原型，持续完善）

- 俯瞰图按[冬木市地图取舍](fuyuki-geography.md)呈现深山町、新都、未远川及两座可通行的桥；14 个现有地点分布在两岸多条道路上。
- 街区道路使用同一张可滚动的 2D 城市画布；角色可用键盘、触屏和手柄沿路行走。地点卡可让当前人物沿路前往，抵达后进入对应近景继续移动；街区上的「进入街景」也可直接前往。
- 街景与俯瞰图共用人物位置、时间和存档；可从住宅门前进入现有室内视图。
- 已完成：减慢人物步速；俯瞰图与街区底图换成同一张原创绘景；咖啡店与商店侧巷可以不返回俯瞰图、直接在近景中沿街走到下一处。
- 待完成：逐段补齐深山町、跨河与新都其他地点之间的近景道路和入口，检查新地点与旧存档的位置关系；当前仍是 2D 可玩原型。

## 11. 公共地点交互

- 给学园、咖啡店、商店侧巷和河岸公园增加地点专属的进入或互动入口。
- 到场后提供与地点相符的活动，反映在日常、花销、关系和事件记录中；限制不在场时的操作。
- 验收：四处地点都可实际触发并记录互动，离开后状态仍正确。

## 12. 住宅门前与室内行走

- 从街景门前进入对应住宅，补齐室内可行走区域、房间切换和返回街道的连续体验。
- 保留现有在家/外出、睡眠、来访与交谈规则；室内外同一人物不能重复出现。
- 验收：十处住宅可进出，人物位置和日常状态在切换、刷新及恢复后保持一致。

## 13. 人物现场生活与互动

- 扩展居民在街区的行走、停留、相遇和现场交谈表现，让场景里发生的事对应现有日常记录。
- 增加接近人物后的交互提示，处理忙碌、睡眠、室内和离场等边界。
- 验收：能跟随居民跨地点行动并在有效距离交互，重复操作不会制造虚假事件。

## 14. 2D 镜头和操作手感

- 完善街景平移、缩放、跟随、切换人物、触屏方向操作和手柄提示；保留俯瞰图的快速定位。
- 优化街景切换过渡、夜间画面、加载提示与低性能设备体验。
- 现有 14 张独立绘景可用于地点近景行走，但不能直接拼成跨街区全景；若要达到完整游戏场景的美术质量，还需制作相互衔接的道路、河岸及建筑素材，替换当前统一视角的简化布景。
- 验收：桌面与手机操作清楚、移动不误触，长时间运行无明显卡顿或位置跳变。

## 15. 存档、云端与发布验收

- 覆盖新增地点及互动的本地存档、导入导出、云端上传恢复和旧版迁移。
- 检查素材大小、加载时间、无障碍、主要浏览器与正式部署；发布前完成回归测试。
- 验收：本地与云端恢复后场景、人物和记录一致，正式站点关键流程可用。

## 16. 3D 可行性样板

- 用一段街道、一位人物做真正可绕视角观察的 3D 样板：模型、骨骼动作、镜头、碰撞和一处互动。
- 实测桌面与手机性能、素材制作量和现有 2D 存档/日常规则的接入方式，再确定完整 3D 的范围。
- 验收：人物能在 3D 场景行走、环视和互动，有明确的设备性能与制作成本记录。现有 2D 行走图不能直接变成可环视的 3D 模型。

## 17. 扩展 3D 街区（以第 16 条样板结果为前提）

- 按样板确定的技术和素材标准，逐区制作 3D 环境、人物与动作，接入现有地图、生活模拟和存档。
- 让 2D 街景继续可用，避免 3D 尚未覆盖的地点失去玩法。
- 验收：计划内区域能完整行走、环视、互动和跨区移动；数据与 2D 模式一致。

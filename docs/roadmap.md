## 2D 打磨阶段：先做出好玩的样板，再扩展全城

目标是让玩家喜欢在冬木市停留、主动寻找人物、愿意观察自己选择造成的变化。保留自由日常与原有人物关系，不为追求“任务量”强加战斗或打卡。以下完成标准同时看**画面、操作、内容和实际试玩感受**；自动化测试只证明功能正确。

参考现有作品的方法，不复制其素材与设定：

- [《星露谷物语》](https://www.stardewvalley.net/about/)：居民各有日程，关系发展带来个人事件、秘密与节日；借鉴“每天想再见谁”的日常节奏。
- [《林中之夜》](https://playism.com/en/game/nitw/)：城镇探索、人物与多样对话互相支撑；借鉴“重访熟悉地点仍能发现新内容”。
- [《Spiritfarer》](https://thunderlotusgames.com/games/spiritfarer/)：照料、动作、手绘环境共同表达与人物的关系；借鉴可触摸的日常细节与情绪反馈。
- [《风来之国》](https://eastwardgame.com/media/)：有辨识度且细节丰富的 2D 场景；借鉴场景层次、光影和构图，不直接改成像素画风。
- [《Coffee Talk》](https://store.steampowered.com/app/914800/Coffee_Talk/)：把有限场所内的交谈与人物故事做深；借鉴少量互动也能留下后续影响。

### 当前推进原则（2026-10-03）

本轮先让人物正常生活，让交谈影响记忆与后续行动，并补少量完整的日常玩法；完成第 16—22 条后再打磨美术小样。保留第十五条及地图、身份补丁的基础框架，已有机制以补齐和验收为主。

- **可玩性与 UI 是每条的验收要求。** 操作入口清楚，成功、拒绝、等待和后续都有可理解的反馈；桌面与手机都能使用，不靠密集日志或纯数值变化表达全部过程。
- **暂缓美术小样不降低审美要求。** 继续参考用户确认的融合版：P1 的自然光影、P2 的动画背景笔触、P3 的舒适构图；日式普通街道、非像素、清楚柔和的层次。UI 用克制的色彩、足够的文字对比和一致的留白，不以粗糙占位画面作为验收成果。
- NPC 自主行动，玩家控制的人物由玩家决定执行；不开收费 AI 仍能正常生活并参与基础活动。手动、自主及已启用的后台运行使用相同的生活规则。
- 每完成一条单独汇报并记录真实验收结果。付费 AI 实测仍暂缓；不自动开启代管或增加请求预算。
- 旧编号第 16、17 条属于历史探索；废弃视觉和 3D 实验已从活动源码移除，现行编号以下列七条为准。

## 16. 基础生活的完整过程 — 已完成（2026-10-03）

## 17. 统一手动交谈与自主交谈的结果 — 已完成（2026-10-04）

- 两种交谈共用关心、摩擦、偏好、邀请、拒绝的结果规则，明确区分随口表达、提议和双方确认。
- 每项结果都有对应原话和正确人物身份；拒绝、改条件、没有明确答应或不可执行的内容不能形成原约定。基础预设对话也能走完该过程。
- UI 给出简短结果反馈，不让普通交谈每次都强行改变关系；AI 不把未发生的行动当作完成。
- 验收：同一有效交谈由两种入口产生一致结果；重复提交、切换人物、过期回复不重复记忆或安排。
- 已完成：手动与自主共用有原话依据的结果；新增免费关心、明确兴趣与三种邀请，回复下方和日常记录可查看成立或拒绝原因。211 项测试、构建、实际桌面/手机交谈和刷新恢复通过，详见[第 17 条验收](verification-conversation-results-2026-10-04.md)。长期个人记忆仍按第 18 条继续。

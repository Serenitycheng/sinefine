# 冬木市地图取舍

本项目的地图是**可行走的原创改编图**，不是《Fate》原作地图的逐点复刻。角色同住、切嗣一家新居、韦伯与肯尼斯等人的住处，以及部分商店和第二座桥，服务于本项目的日常玩法，不代表原作设定。

- **区域骨架：** 北侧入海，南侧山地；未远川分开西侧深山町与东侧新都。深山町采用坡道、分岔与旧街巷，新都使用较宽的主街、站前街和河岸步道，保留各自的城区特点。
- **地点关系：** 卫宫宅通往学园坡道、深山中心路口和冬木大桥。远坂宅与间桐宅相邻，间桐宅在另一层坡地；韦伯住处移到深山町。深山商店街接入中心路口，柳洞寺沿圆藏山参道向南离开住宅区。教会保留在新都丘陵侧。
- **改编边界：** 肯尼斯的日常住处是新增住宅，不等于原作凯悦酒店。切嗣一家新居、娜塔莉亚住处、咖啡店与南桥仍属于本项目改编。中央公园、站前街是地理背景，不冒充本轮已经制作的新玩法。
- **地图和行走：** `fate-city-layout.ts` 的 19 条折线道路同时驱动绘图、道路碰撞、寻路和街边交谈距离判断，取消旧版规则矩形道路网。14 处入口仍可定位、前往及交互。既有近景插画保留作地点参考，不作为逐张切换的连续世界。现有美术图集和 3D 样板尚不是最终视觉品质。
- **样板与存档：** 卫宫宅—学园样板的坐标、比例与交互保持不变。本轮日常存档格式升级为 v16：v15 城市存档中的住宅附近人物随地点迁移，途中人物吸附到新道路并重新寻路，已在做的活动保留剩余时间、需求、金钱与经历；室内坐标保持原房间。v14 及更早版本先执行旧坐标换算。原始记录不在读取时覆盖，迁移后的存档可再次读取而不会重复迁移。

参考：[TYPE-MOON《Fate/stay night》故事介绍](https://www.typemoon.com/products/fate/story/index.html)确认冬木市为海山环绕的城市；[TYPE-MOON 官方冬木市 MAP 商品说明](https://typemoon.com/news/2025/CziQj0)确认原游戏具有地图画面；[TYPE-MOON Wiki 的冬木市条目](https://typemoon.wiki.cre.jp/wiki/%E5%86%AC%E6%9C%A8%E5%B8%82)整理了《Fate/side material》等资料中的深山町、新都、未远川、卫宫宅到柳洞寺山道及冬木大桥的关系。后二者的网页说明不等于授予地图图片转载许可，因此仓库使用原创绘景。

[TMdict 收录的《Fate/Zero Animation Visual Guide I》深山町条目](https://www.tmdict.com/ja/fu.fuyuki-city-miyama-town)用于复核麦肯齐家／韦伯住处的区域归属。以上资料支持区域与相邻关系，不提供本项目使用的精确坐标；道路距离和比例经过玩法压缩，没有宣称逐点复刻官方地图图片。

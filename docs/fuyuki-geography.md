# 冬木市地图取舍

本项目采用可行走的原创改编图，以原作区域关系为基础，距离和比例为日常玩法压缩，不宣称逐点复刻官方地图。

- **区域骨架：** 北侧入海、南侧山地，未远川分开西侧深山町与东侧新都。深山町使用坡道、旧巷和分岔，新都有较宽的主街、站前街及河岸步道，取消规则矩形道路网。
- **地点关系：** 卫宫宅接入学园坡道、深山中心路口和冬木大桥；远坂宅与间桐宅位于相邻洋馆坡地；韦伯住处和商店街归于深山町；柳洞寺沿圆藏山参道离开住宅区；教会保留在新都丘陵侧。
- **改编边界：** 切嗣一家新居、肯尼斯和娜塔莉亚的日常住处、咖啡店与南桥属于本项目改编。肯尼斯的新住宅不等于原作凯悦酒店。中央公园和站前街作为地理背景，不代表新增互动任务。
- **地图与行走：** `fate-city-layout.ts` 的 19 条折线道路共用绘图、碰撞、寻路和现场交谈判断；住宅另有通到实际门前的入户步道。14 处地点保留编号和交互，建筑避开可走路面。街区与地图使用融合版视觉素材；地点近景插画仅作卡片参考，不逐张切换为行走背景。
- **存档兼容：** 地图补丁从日常存档 v16 起迁移旧地图，这是数据格式编号，与开发步骤第十六条无关。旧 v15 住宅附近人物随地点迁移，途中人物落到新道路重新寻路；已有活动、需求、收支和经历保留，室内房间坐标保持。v14 及更早记录先换算旧坐标。后续生活机制版本继续兼容该迁移，不修改传入记录，不重复迁移。
- **当前制作范围：** 废弃街景与 3D 样板已从活动源码清理。保留现有基础机制，先收尾操作，再分别打磨小范围玩法与融合版美术，不将当前素材质量表述为最终验收。

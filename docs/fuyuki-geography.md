# 冬木市地图取舍

本项目的地图是**可行走的原创改编图**，不是《Fate》原作地图的逐点复刻。角色同住、切嗣一家新居、韦伯与肯尼斯等人的住处，以及部分商店和第二座桥，服务于本项目的日常玩法，不代表原作设定。

- **区域骨架：** 未远川分开西侧的深山町和东侧的新都；住宅、学园和柳洞寺位于深山町侧，教会和较新的商业街位于新都侧。冬木大桥连接两岸。河岸公园放在新都近河处。
- **路线关系：** 卫宫宅所在住宅区通向深山町的学园、商店街和柳洞寺山道；跨河后抵达新都。第二座南桥与规则化的街道网是为了让角色能连续行走而增设。
- **画面边界：** 当前俯瞰图与行走底图共用同一张原创绘景和坐标，地点近景是单独插画。咖啡店与商店侧巷之间已能在近景中沿街行走；其余地点间的近景道路素材还需逐段制作，不能把现状称作完整无缝街景。

参考：[TYPE-MOON《Fate/stay night》故事介绍](https://www.typemoon.com/products/fate/story/index.html)确认冬木市为海山环绕的城市；[TYPE-MOON 官方冬木市 MAP 商品说明](https://typemoon.com/news/2025/CziQj0)确认原游戏具有地图画面；[TYPE-MOON Wiki 的冬木市条目](https://typemoon.wiki.cre.jp/wiki/%E5%86%AC%E6%9C%A8%E5%B8%82)整理了《Fate/side material》等资料中的深山町、新都、未远川、卫宫宅到柳洞寺山道及冬木大桥的关系。后二者的网页说明不等于授予地图图片转载许可，因此仓库使用原创绘景。
